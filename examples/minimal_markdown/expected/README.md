# expected/

This directory holds the **reference outputs** for the minimal_markdown
example, so a reader can see the produced look-and-feel without having to set
up Word + pywin32 locally.

## preview.png

A 4-page contact-sheet rendering of `final.pdf` produced on a Windows machine
with Microsoft Word. The committed image is intentionally generated against a
**real Chinese-thesis template** (the Zhengzhou University undergraduate
thesis template, V2) so the screenshot shows what the skill produces on a
realistic strict template — bilingual cover, English title page, and the
"原创性声明" / "授权书" front matter. The names and numbers visible on the
cover ("李四" / "王五" / "10459") are the **placeholder values shipped inside
the school template itself**, not real student data.

It was generated by running `run_example.py` against that template and
copying the resulting `final.preview.png` into this folder:

```bash
python examples/minimal_markdown/run_example.py \
    --template /path/to/your-real-thesis-template.docx
cp examples/minimal_markdown/final.preview.png \
   examples/minimal_markdown/expected/preview.png
```

Without `--template`, `run_example.py` falls back to the lightweight
`build_template.py`-generated sample, which is intentionally minimal (one
cover style, one body style, one heading) and produces a much simpler
preview. The committed `expected/preview.png` is **not** the output of that
default path; it is provided to demonstrate behaviour on a realistic
institutional template.

If you're not on Windows, you can still inspect the docx outputs:

- `examples/minimal_markdown/final.docx` — open in Word / LibreOffice
- `examples/minimal_markdown/sample_template.template-report.json` — JSON dump
  of the template's styles, paragraphs, and OOXML hints.
